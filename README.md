# RevenueLeak OS

RevenueLeak OS is a Next.js application scaffold for a revenue recovery platform focused on home-service operators. This branch lays out the route groups, domain modules, feature components, API stubs, and Prisma schema requested for the product application structure.

## Stack

- Next.js App Router with TypeScript
- Tailwind CSS
- Prisma schema and seed scaffold
- Domain-oriented data, services, validators, and UI components

## Getting started

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` before working with Prisma-backed features.
